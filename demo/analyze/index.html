Nothing leaves your browser. This page declares a security policy the browser enforces: no data requests (connect-src 'none'), nothing loaded from other addresses (default-src 'none'), no form submissions (form-action 'none'), no <base> element to redirect the page's links (base-uri 'none'). So once the page's own files have loaded, it cannot fetch or send anything; an automated test fails the build if it ever makes a request. Links you click yourself still open as usual and carry none of your data. The only entries in your browser's Network tab are this page's own files and blob: URLs. Consequence: replays cannot fetch an experiment's external stylesheets or images from the web — drop them alongside the data to get styled replays, or use the CLI.
